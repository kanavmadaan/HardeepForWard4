# Hardeep Ghuman Ward 4 Website

Static multi-page website for Hardeep Ghuman's Ward 4 Halton Hills campaign.

## Open the site

Open `index.html` in a browser.

## Photo replacement

Add your real photos to:

`assets/images/`

You need **10 JPG photos total** named exactly:

`1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, `5.jpg`, `6.jpg`, `7.jpg`, `8.jpg`, `9.jpg`, `10.jpg`

The site will show clean "Add photo" boxes until the matching JPG file is added. `1.jpg` is the candidate portrait/headshot.

Full photo checklist is in `docs/SOURCE_NOTES.md`.

## Ward 4 map

The Ward 4 map appears on the homepage after the Ward 4 information section. Files:

- `assets/images/ward-4-georgetown-south-map.png`
- `docs/Ward-4-Map.pdf`

Open any `.html` file in a code editor and edit the visible text. The shared design is controlled by `assets/styles.css`.
